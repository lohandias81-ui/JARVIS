# Jarvis

Versão 1.0

IA única em uma página HTML: chat em português, voz (falar e ouvir), cotações de cripto pelo CoinGecko, mini jogo de NPCs e classificador kNN.

## Como usar

Abra o arquivo `index.html` no navegador ou publique com GitHub Pages.

## Limites

- Não navega na internet nem pesquisa no Google.
- Não guarda memória entre visitas.
- Cotações dependem do conector CoinGecko estar disponível na visualização.
